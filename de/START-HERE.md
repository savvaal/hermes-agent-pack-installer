# Start hier — Premium Hermes Agenten-Pack

Dieses Paket installiert ein deutschsprachiges Agenten-System für Hermes.

## Kundeninstallation später

Ziel-Command:

```bash
curl -fsSL https://deine-domain.de/install.sh | bash -s -- --token VIP_TOKEN
```

Alternativ als GitHub-Variante:

```bash
git clone https://github.com/DEIN-ACCOUNT/hermes-agent-pack-installer.git
cd hermes-agent-pack-installer
./bootstrap-de.sh --token VIP_TOKEN
```

## Enthaltene Agenten

- **Viral Reel Generator 5.0** — Reels, Hooks, Skripte, Post-Struktur.
- **Storytime Agent** — persönliche Storys, Storytelling, Episoden, Narrative.
- **Community Funnel Builder** — Telegram/WhatsApp Community Funnel, Onboarding, DM-Flows.

## Prinzip

Der Kunde kopiert nur eine Command-Zeile. Der Installer:

1. prüft VIP-Token,
2. installiert Hermes, falls nicht vorhanden,
3. installiert die Agenten-Dateien,
4. legt ein Premium-DE Profil an,
5. zeigt die nächsten Schritte.
